# Credit Scoring Problem
Описание проекта

Данный проект посвящён построению модели кредитного скоринга — системы оценки платёжеспособности клиентов банка. Целью является предсказание вероятности дефолта клиента на основе его финансовых и демографических данных.

Данные

Использован датасет, содержащий информацию о клиентах и их кредитной истории. Данные включают различные признаки, такие как возраст, доход, кредитная история и другие. Датасет доступен по ссылке: [Credit Score Classification Dataset](https://www.kaggle.com/datasets/wordsforthewise/lending-club/data).

Этапы работы (6)

1. Загрузка и предобработка данных
   
Загрузка данных и первичный анализ структуры.

Обработка пропущенных значений и аномалий.

Кодирование категориальных признаков.

Масштабирование числовых признаков.


2. Разведочный анализ данных (EDA)

Анализ распределения признаков.

Выявление корреляций между признаками.

Визуализация распределений и взаимосвязей.



3. Балансировка классов

Обнаружение дисбаланса классов (дефолт / не дефолт).

Применение методов балансировки, таких как oversampling, для улучшения качества модели.


4. Построение моделей

Обучение нескольких моделей машинного обучения:

Логистическая регрессия

Случайный лес (Random Forest)

Градиентный бустинг (LightGBM)

Нейронные сети (MLP)

Настройка гиперпараметров с использованием кросс-валидации.


5. Оценка моделей

Использование метрик:

F1-мера

Precision

Recall

ROC-AUC

Выбор оптимальной модели на основе F1-меры.


6. Интерпретация модели с помощью SHAP

Применение SHAP для объяснения предсказаний модели.

Визуализация важности признаков и их влияния на предсказания.

Построение waterfall-графиков для отдельных наблюдений.


7. Выбор метрики: F1-мера

В данной задаче была выбрана F1-мера в качестве основной метрики, поскольку она учитывает как точность (precision), так и полноту (recall). Это особенно важно в банковской сфере, где необходимо минимизировать как ложные положительные, так и ложные отрицательные предсказания.

8. Приоритет на Precision

Для вымышленного примера, следуя банковской практике, было принято решение максимизировать точность (precision), даже если это приводит к некоторому снижению полноты (recall). Это обусловлено тем, что ложное одобрение кредита (false positive) может привести к финансовым потерям для банка, тогда как отказ в кредите платёжеспособному клиенту (false negative) менее критичен.

9. Заключение

Построенная модель позволяет эффективно предсказывать вероятность дефолта клиентов, обеспечивая баланс между точностью и полнотой. Использование SHAP позволяет интерпретировать предсказания модели, что важно для принятия обоснованных решений в банковской сфере.
